# Upstream 0.21.9 Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate upstream Codeg `v0.21.9` into MyCodeBuddy, preserve fork policy and behavior, and leave a verified local `main` at version `0.21.9-mycodebuddy.1`.

**Architecture:** Perform one ancestry-preserving merge on a dedicated `sync/codeg-0.21.9` branch. Resolve conflicts in dependency order: release metadata and translations, sidebar/UI state, message rendering, frontend ACP contracts, then Rust ACP core. Verify and commit the resolved merge on the sync branch, fast-forward local `main` to that merge commit, and rerun the full gate.

**Tech Stack:** Git merge (`ort`), Next.js 16, React 19, TypeScript strict mode, Vitest, Tailwind CSS v4, Rust 2021, Tauri 2, Axum, SeaORM, pnpm.

## Global Constraints

- Target exactly `v0.21.9` at `e540a4fa75cb739db319fa8ce9482690c8be8e57`; do not merge a newer upstream tip.
- Preserve published MyCodeBuddy history; no rebase, force-push, or history rewrite.
- Final fork version is exactly `0.21.9-mycodebuddy.1`.
- Preserve MyCodeBuddy branding, repository metadata, updater endpoints, installer, signing, compliance, and Windows-only release policy.
- Preserve reviewed OpenClaw deletions and functional fork behavior; compose incoming fixes around them.
- Do not modify, remove, or clean unrelated branches and linked worktrees.
- Do not commit while `git ls-files -u` is non-empty.
- The conflicted merge permits only one final merge commit; intermediate tasks stage resolved paths and run focused checks instead of making partial commits.
