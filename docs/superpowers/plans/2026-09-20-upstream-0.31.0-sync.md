# Upstream Codeg 0.31.0 Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge Codeg `v0.31.0` (`upstream/main` @ `aace536fe`) into MyCodeBuddy on `sync/codeg-0.31.0`, resolve conflicts per the design, verify, then merge to `main`.

**Architecture:** No-ff merge of `upstream/main` onto a sync branch cut from `origin/main`. Resolve with TAKE_OURS / TAKE_THEIRS / MERGE_BOTH / REWRITE per `docs/designs/2026-09-20-upstream-0.31.0-sync-design.md`. Ship `0.31.0-mycodebuddy.1`. Do not merge to `main` until the verification gate is green.

**Tech Stack:** Git (ort merge), pnpm, Vitest/ESLint, Rust/Cargo (lib + server feature matrix), existing UPSTREAM cookbooks.

**Spec:** `docs/designs/2026-09-20-upstream-0.31.0-sync-design.md`

## Global Constraints

- Identity version must be exactly `0.31.0-mycodebuddy.1` in package.json, Cargo.toml, Cargo.lock (`codeg` package), tauri.conf.json.
- DrawCode / app.mycodebuddy branding stays; bare upstream `codeg` / `app.codeg` identity must not win.
- OpenClaw stays deleted (grep gate after resolve).
- Parent delegation tools list length == 6 (fork directory); no taskboard companion tools.
- Work on `sync/codeg-0.31.0` only; never resolve directly on `main`.
- Prefer Linux VM / cloud agent for git+build; do not operate on the user's personal Windows machine for Codeg/git.
- Re-probe with `git merge-tree --write-tree origin/main upstream/main` if either tip moved since design.
