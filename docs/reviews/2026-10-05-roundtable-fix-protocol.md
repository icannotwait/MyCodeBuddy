## Interfaces and integration handoff

- Storage worker owns populating every `ProjectionReplayV1` field from the same write transaction and fixed historical reads. A full projection must include **all** messages/memberships/evidence at H, not just the transaction's changed entity IDs. Historical `projection()` must use stored body membership when validating referenced objects, rather than current membership filters. These requirements were sent to the storage worker before edits.
- `ProjectionBodyV1` literals add `messages`, `evidence_manifests`, and `replay`; root owns the transport test literal, storage owns acceptance literals.
- `resyncRoundtable(accepted, highWaterSeq, status?, closedAttemptIds?)` and `resyncAfterReconnect` use the same contract. `reduceRoundtable(view, event)` no longer takes `seen`. Product integration must feed the immutable snapshot H and terminal/accepted attempt IDs, and verify projection room/hash/schema before passing a projection snapshot to the reducer.
- The manifest helper validates object binding. **Authenticated service cursor scope is implemented by the shared `ScopedCursors` pool and connected by root**: UUIDv4 capability tokens bind principal, room, projection and manifest to the validated underlying versioned offset. They expire after 15 minutes; issuance removes expired entries and caps the pool at 10,000. Mismatch, unknown and expired tokens are rejected. The raw versioned offset is never the external capability token.
- The protocol aggregate retains `messages`/`evidence_manifests` for the loader's existence proof; `project()` places those refs into the hash. `ResultScope` and its visible aliases/history now derive Serde traits so sealed candidates can retain their original alias scope.
